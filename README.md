# SolverCoach forecast releases

The latest forecast release for each SuperCoach Classic game, read directly by
https://solvercoach.lakebed.app. Each `<sport>/latest.json.gz` is the gzipped
JSON payload the site's solver consumes; `<sport>/latest.meta.json` describes
it (season, round, update time, version hash, size). This repository holds
only the current release; history is archived privately.
